# Sales Intelligence Dashboard

## 🔗 Live Demo
[View Project](https://cognitive-capital-paresh.netlify.app/)

Cognitive Capital is an interactive Sales Intelligence Dashboard designed to present business performance and sales insights through a clean, modern interface. It provides an overview of key performance indicators, revenue trends, product performance, regional sales, customer segments, and returns using interactive charts and visualizations.

The dashboard is built using **HTML, CSS, JavaScript, and Chart.js**. It includes filters for year, region, category, customer segment, payment method, and sales channel, along with a reset option and light/dark theme toggle. The Export Dataset feature is intended to download the dataset from the connected Google Sheets workbook in Excel format.

This project was developed as part of a data analytics dashboard project, focusing on presenting sales information in an accessible and visually engaging format. The dashboard files are organized into separate HTML, CSS, and JavaScript files for easier maintenance and future improvements. The project can be run locally by opening `index.html` in a browser or deployed using a static hosting platform such as Netlify.
